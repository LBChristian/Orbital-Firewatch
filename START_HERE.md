# ORBITAL FIREWATCH — Claude Starter Kit

Start with `00_SETUP_AND_RESOURCES.md`.

Then:
1. Create/clone the GitHub repository.
2. Copy this kit's contents into the repository root.
3. Install and sign in to Claude Code.
4. Set up a local FIRMS MAP_KEY in `.env` when available; never commit it.
5. Open Claude Code in the repository.
6. Paste `01_MASTER_BUILD_PROMPT.md`.

Files:
- `01_MASTER_BUILD_PROMPT.md` — full game-building prompt.
- `CLAUDE.md` — persistent project-specific instructions for Claude Code.
- `00_SETUP_AND_RESOURCES.md` — setup steps, NASA APIs, libraries and asset resources.
- `ASSET_CREDITS_TEMPLATE.md` — track asset licenses and NASA provenance.
- `proposal/` — original proposal document plus searchable Markdown extraction.
- `reference-art/` — generated visual references. These are illustrative only; embedded map detections and numbers are not verified NASA data.

Important: this kit is a build brief, not a prebuilt game. Claude Code must implement and test the application.
